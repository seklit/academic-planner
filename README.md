| 功能 | 效果 |

## 🚀 安装（30 秒）

### 前提

- 已安装 [WorkBuddy Desktop](https://www.codebuddy.cn/)
- 支持导入自定义 Skill

### 步骤

| 步骤 | 操作 |
|------|------|
| **1** | 下载本仓库的 `academic-planner.zip` |
| **2** | 打开 WorkBuddy Desktop |
| **3** | 点击左侧 **Skill 面板 → 管理 → 导入** |
| **4** | 选择刚才下载的 `academic-planner.zip` |
| **5** | 创建或打开一个 **工作区**（任意空文件夹就行） |
| **6** | 在工作区对话框中输入：**`部署学业规划`** |

然后 AI 会自动开始对话，问你课表、DDL、有没有长期项目等。

你回答完，AI 直接生成全套文件 + 可打开的仪表盘。

## 🎯 能做什么

### 第一天

```
你：「部署学业规划」
AI：「好的，先问几个问题——
      你的名字、专业、每周课表、最近的DDL……」
你：「我叫小明，清华AI专业，周一上午高数一教101，
      周三下午线代理教201，最近有数学作业5/25交……」
AI： ⚡ 写入课表 / DDL / 个人信息
     ⚡ 生成仪表盘 + 周视图
     ⚡ 告诉你已就绪
     ⚡ 询问要不要配微信推送
```

全程 3 分钟，不用碰任何文件。

### 日常使用

| 你说 | AI 做什么 |
|------|----------|
| 「今天有什么课」 | 读取 data.js，返回今日安排 |
| 「周三加一节课：马原 09:50-12:15 三教301」 | 写入 data.js，同步 timetable.md |
| 「数学作业做完了」 | 标记作业完成，更新统计 |
| 「新 DDL：OO 大作业，6/1 交」 | 添加到作业池，自动算天数和紧急标记 |
| 「这周数据怎么样」 | 读取统计，汇报学习时长和进度 |
| 「配个微信推送」 | 引导你注册 Server酱，配置 notify.py |

### 微信推送（可选）

配好之后，每天自动推送：

| 推送 | 时间 | 内容 |
|------|------|------|
| 🌅 早安课表 | 07:30 | 今日课程 + 紧急 DDL 提醒 |
| 📢 DDL 检查 | 19:00 | 扫描 1-2 天内到期的任务 |
| 🏋️ 健身督促 | 21:00 | 健身日提醒（可配置） |
| 🌙 晚安总结 | 22:30 | 回顾 + 鼓励 |

需要免费注册 [Server酱](https://sct.ftqq.com/) 获取 SendKey，AI 会引导你完成。

## 📁 项目文件

```
your-workspace/
├── index.html           ← 仪表盘（浏览器打开）
├── weekly.html          ← 周视图
├── modules/             ← JS 模块（不动）
├── data/                ← 你的数据（AI 维护）
│   ├── data.js          ← 课表 + DDL + 统计
│   ├── timetable.md     ← Markdown 课表
│   └── assignments.md   ← Markdown 作业池
├── tools/
│   ├── sync-data.py     ← Markdown → data.js 同步
│   └── notify.py        ← 微信推送脚本
└── .workbuddy/
    ├── IDENTITY.md      ← AI 角色定义
    └── USER.md          ← 你的个人信息
```

## 🔧 技术说明

### 数据格式

`data/data.js` 中的 `SCHEDULE_DATA` 结构：

```javascript
{
  "courses": {
    "1": [ // 1=周一
      {"t":"09:50-12:15","n":"课程名","type":"class","loc":"教室"}
    ]
  },
  "assignments": [
    {"name":"作业名","ddl":"5/25(周一)","days":5,"urgent":true,"done":false}
  ],
  "stats": { "courseHours": 12, "pendingCount": 3, "freeHours": 24, "fitnessDays": 3 },
  "weekRange": "5月19日~5月25日"
}
```

### 时间槽

| 节次 | 时间 |
|------|------|
| 第一大节 | 08:00-09:35 |
| 第二大节 | 09:50-12:15 |
| 第三大节 | 13:30-15:05 |
| 第四大节 | 15:20-16:55 |
| 第五大节 | 17:05-18:40 |
| 第六大节 | 19:20-21:45 |

### 迭代路线

- **v1** — 封装为独立项目（模块化、数据/逻辑分离）
- **v2** — 封装为 WorkBuddy Skill（对话引导部署三阶段：采集→写入→推送）
- **v3** (计划) — 多用户模板、网络学堂自动同步、智能周报
